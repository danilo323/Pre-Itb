# Regla de Consulta de Memoria (.gemini/memoria.md)

Siempre al comenzar una interacción o antes de planificar un cambio en este proyecto:
1. Lee el archivo `.gemini/memoria.md` para conocer el estado actual, decisiones arquitectónicas, rama de git en uso y acuerdos previos.
2. Mantén actualizada la memoria cuando el usuario realice solicitudes de características o cambios significativos.
